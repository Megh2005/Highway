Highway is a browser-based interactive map for viewing, measuring, editing, sharing, and printing important roads in Kolkata. The application is delivered as one self-contained index.html file and uses Leaflet 1.9.4 for the map, OpenStreetMap tiles for the basemap, OpenStreetMap Nominatim for bounded Kolkata highway search and reverse geocoding, public OSRM-compatible routing services for driving paths, and Firebase Firestore for synchronized user-created highways. The initial built-in road is EM Bypass, identified as R10, with its colour, start and end landmarks, and geographic coordinates already configured. Each road has a code, name, colour, start label, end label, start coordinate, end coordinate, and optional via-points. Roads are drawn with a dark outline and coloured line, labelled along their route, and marked with S and E endpoint markers. The map includes zoom controls, a scale, a north arrow, a legend, a Fit button, and a status area. Selecting a road highlights it and opens a detail popup containing its code, colour, start and end information, coordinates, routed length, estimated driving time without traffic, whether the path follows the street network or is a straight-line fallback, a warning when the routed distance is much longer than the direct distance, and a link to open the route in OpenStreetMap. Routing requests are cached in local storage, attempted through two servers with retries, queued one road at a time, and replaced by a straight line with an explicit status warning if routing is unavailable. Custom roads are stored in the Firestore highways collection and are updated live on every connected device; database permission or service errors are shown in the toolbar. The add/edit panel validates required values and duplicate codes, assigns the next available R-number and palette colour, supports manual endpoint dragging and endpoint swapping, and preserves via-points to keep routing on the selected highway. The print system supports A4, A3, A2, and Letter paper, landscape or portrait orientation, print margins, automatic map fitting, and browser printing or PDF saving.

After the deployment link is opened, the browser loads the page, initializes the Leaflet map, connects to Firebase, displays the Kolkata basemap, loads the built-in EM Bypass, listens for custom highways, and queues route calculations. The user can pan and zoom, click Fit to frame all available roads, click any road or endpoint to inspect its popup, follow the OpenStreetMap route link, and read the legend to identify road codes and colours. To add a highway, the user selects Add highway, types at least two characters of a Kolkata road name, waits for Nominatim autocomplete results, and chooses a highway result. The application loads its geometry, determines the northern and southern endpoints, chooses intermediate via-points, places draggable S and E markers, reverse-geocodes endpoint labels, assigns a new code and unused colour, and shows a preview. The user can edit the code, name, colour, endpoint labels, marker positions, or direction, then selects Save highway; the record is written to Firestore and immediately appears on the map and on other open devices. Selecting a custom road allows Edit or Delete; deletion is also available beside custom roads in the legend, and failed database actions remain visible as an error instead of being silently ignored. To print or save a PDF, the user chooses a paper size and orientation, selects Print, waits while the basemap finishes loading, and uses the browser print dialog; controls and editing panels are hidden and the map is fitted to the roads for a clean page. If a routing, search, network, or Firestore service is unavailable, the interface reports the problem, keeps usable map data where possible, and allows the user to retry or continue with the available fallback.
